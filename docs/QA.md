# Quality and call-center figures

Supervisors score a call, a ticket, an escalation, or a retention talk. The form has weighted items. If a critical item scores zero, the whole evaluation becomes the percent in Settings, which starts at 0%. Saving a change to the form stores a new version. Older scores keep the version they were given.

Each week the sampler takes the first N calls for each call-center agent, oldest first, and does not pick the same call again. N starts at 5 and is edited in Settings.

An agent sees only their own scores. A supervisor sees the team. A sales manager scores sales calls and retention talks. Management and an auditor can read every score.

The period page shows calls, average handle time, after-call work, first-contact resolution, callbacks on time, leads, conversion, tickets resolved at the first tier, SLA met, quality average, and customer score. Each figure links to the records it came from. Abandoned calls stay “n/a” until a phone system is connected.

When two people score the same call, ticket, escalation, or retention talk, the page shows both totals and the difference.

Agent status (available, on a call, break, training, offline, after-call work) is a time log. The page shows how many seconds the selected person spent in each status for the chosen dates.

The figures are listed in [to-confirm.md](to-confirm.md).
