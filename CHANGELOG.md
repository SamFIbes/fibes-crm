# Changelog

## 2026-11-09

Admins can now bring staff from Hub ERP into fibes CRM with one command. Each person arrives switched off with no access, so nobody can sign in until an admin turns them on and gives them a role. Existing accounts are left alone, and no emails, invites or password resets go out. A dry run shows the counts first.

Pull request: https://github.com/SamFIbes/fibes-crm/pull/13

## 2026-11-08

The sign-in page has a calmer animated background and a clearer form card. Email, password, remember-me, forgot-password, and sign-in itself work the same way as before.

Pull request: https://github.com/SamFIbes/fibes-crm/pull/11
