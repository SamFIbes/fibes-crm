# Changelog

## 2026-11-12

The dashboard now has a sales overview. It shows new leads, new opportunities, won deals and open deals for the dates you pick, with charts for weekly leads, weekly deals, monthly wins and won value, where leads come from, and won value by area. Each chart can be shown as a table. Some older tiles were renamed so the name says what they count, for example "Leads by source" is now "New leads".

Pull request: https://github.com/SamFIbes/fibes-crm/pull/43
